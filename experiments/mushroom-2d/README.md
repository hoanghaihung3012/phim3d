# Thử nghiệm: nhân vật Nấm (2D vẽ tay)

Cây nấm cùng nét vẽ với Táo Lém: mũ tím nhạt chấm trắng, thân kem có mặt, tay sợi mì, chân ngắn.
Nấm cao hơn Táo (khoảng 1,6 lần). Tính cách: vui vẻ, hòa đồng, hướng ngoại, nói nhiều; học giỏi, biết nhiều
(đeo kính, giơ ngón tay giảng giải); hơi vô tri; lâu lâu hơi dữ (cau mày, dậm chân) rồi cười lại ngay.
Mũ luôn dính trên đầu, chỉ phồng/xẹp/nghiêng.

- Nhân vật: `src/film2d/characters/Mushroom2D.ts` (dùng chung bộ nét `Sketch` của phim, sẵn sàng đưa vào cảnh).
- Trang thử: `npm run dev` rồi mở `/experiments/mushroom-2d/`; phím 1–8: Chào, Vui, Nói nhiều, Thông thái, Dữ, Vô tri, Hắt xì, Chạy, ô "Đứng cạnh Táo" để so tỉ lệ.
- Preview 1 file: `npm run build:preview -- experiments/mushroom-2d/index`.
